# Eventi Muviti
Archivio pubblico separato: nessun codice privato dell’app o credenziale.

## Aggiungi un evento
Accedi a GitHub come proprietario. Apri Issues → New issue → Aggiungi evento a Muviti. Compila il modulo e premi Create. Attendi l’aggiornamento in Actions, poi ricarica Muviti. Solo gli eventi inviati dal proprietario vengono pubblicati. Modifica il testo della segnalazione per cambiare l’evento; chiudila per rimuoverlo. I dati sono pubblici: non inserire informazioni riservate.

## Aggiornamento
Ogni giorno alle 05:17 UTC e dopo gli inserimenti manuali. Runner GitHub standard su archivio pubblico, senza servizi a pagamento. La raccolta esterna NON è attiva: CataniaToday richiede autorizzazione scritta per scraping/data mining. Prima di attivare altre fonti serve verificarne la licenza. Questo lavoro aggiorna gli eventi tuoi e nasconde quelli scaduti, non cerca ancora nuovi eventi automaticamente.
GitHub può ritardare le pianificazioni e disattivarle dopo 60 giorni di inattività. Controlla Actions; puoi usare Run workflow per aggiornare subito.

## Dati
Data AAAA-MM-GG, ora HH:MM, prezzo 0 se gratuito o vuoto se sconosciuto. Massimo 200 eventi, 300 segnalazioni lette per esecuzione. Nessun’immagine o descrizione viene raccolta automaticamente.
